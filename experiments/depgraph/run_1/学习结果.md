# DepGraph 第一轮：本机已跑通的结果

本轮完成了真实 CIFAR-10 数据上的基线评估、结构化剪枝、1轮微调和独立进程重载。它证明当前环境能开展这条实验路线；完整论文复现仍需按原始配置继续核对版本、稀疏训练、训练轮数和多次重复。

| 模型阶段 | 测试准确率 | 参数个数 | 单张图片计算量（百万，MAC口径） |
|---|---:|---:|---:|
| 作者预训练模型 | 93.53% | 855,770 | 127.116 |
| 刚剪枝的模型 | 15.26% | 562,878 | 59.974 |
| 微调后的模型 | 86.74% | 562,878 | 59.974 |

参数减少 **34.23%**，计算量减少 **52.82%**；计算量比值为 **2.120**。这不代表实际推理速度提高同样倍数，本轮没有测速度。

微调1轮后，准确率较刚剪枝时变化 **+71.48个百分点**。微调后的准确率是固定最后一轮结果，没有按测试集选最佳轮次。

## 这些步骤有什么用

1. **基线**：开始改模型前的参照物。这里加载作者已经训练好的权重，先确认模型和数据处理正确。
2. **剪枝**：真正删掉部分网络通道和相关连接，所以模型参数个数会下降。依赖图帮助相互连接的层一起调整，避免删完以后尺寸对不上。
3. **微调**：在模型删减结构后继续训练，让剩下的参数重新适应任务。精度能恢复多少必须靠实验观察。
4. **保存与重载**：确认结果可以再次打开使用。独立进程重载的固定8张真实图片输出完全一致：**True**。

## 本轮实验设置

- 数据：CIFAR-10，50,000张训练图片、10,000张测试图片，输入为3个颜色通道、32×32像素。
- 测试：三个阶段都使用全部10,000张测试图片。
- 训练：1轮遍历训练集，batch=128；沿用作者 drop_last=True，每轮实际使用 49,920 张，最后不足一个批次的图片略过。
- 剪枝：group_norm，不做稀疏训练；全局渐进剪枝，实际 129 步，目标计算量比2.11。
- 微调：SGD，学习率0.01、动量0.9、权重衰减0.0005，FP32；种子42。单次运行不能支持统计显著性结论。
- GPU：NVIDIA GeForce RTX 3080 Laptop GPU；本进程 PyTorch 峰值已分配显存 408.3 MiB；此值不包含其他程序、驱动和全部显卡占用。
- 软件：PyTorch 2.5.1+cu121，torchvision 0.20.1+cu121，torch-pruning发行元数据 1.6.1。
- 作者代码：v1.6.1，提交 e80127d7c6935c319a7dd6719b8a72e3c1fcbff9；这是后续工具版本，不能视为原始2023代码环境完全一致。
