# DepGraph 第一轮实验计划

目标：验证本机可以完成真实 CIFAR-10 数据上的“预训练模型评估 → 依赖图剪枝 → 微调 → 保存和重载”。

本轮是教学性流程验证，不等同于完整复现 CVPR 2023 全部结果。

- 作者代码：VainF/Torch-Pruning，标签 v1.6.1，提交 e80127d7c6935c319a7dd6719b8a72e3c1fcbff9。
- 模型：作者提供的 CIFAR ResNet-56，复制原模型文件至本实验目录，保留来源与许可证。
- 初始权重：作者 v1.1.4 release 中的 cifar10_resnet56.pth。
- 数据：CIFAR-10；50,000 张训练图片，10,000 张测试图片；输入 3×32×32；使用作者 registry.py 中的数据增强与归一化。
- 环境：项目虚拟环境复用系统已验证可用的 PyTorch/torchvision；新增依赖只装入项目环境。这不是完全隔离的环境，底座版本需一并记录。
- 设置：随机种子 42，FP32，batch=128，Windows 默认 workers=0。
- 剪枝：作者 group_norm 分支对应的 GroupMagnitudeImportance(p=2) + GroupNormPruner，全局渐进剪枝，最多 400 步，目标为原始 MACs / 剪枝后 MACs ≥ 2.11；保留十分类输出层。
- 微调：仅 1 epoch，完整训练集，SGD lr=0.01、momentum=0.9、weight_decay=0.0005；未进行稀疏训练；不选择测试集上最好的模型。

顺序与验收：

1. 在完整测试集评估作者基线，记录准确率、损失、参数量与单张输入计算量。
2. 剪枝后重新评估；参数和计算量应减少，输出仍为 10 类，正确率大于随机猜测仅为基本检查。
3. 使用完整训练集微调 1 epoch，再评估完整测试集。精度是否恢复以实测为准。
4. 保存剪枝模型，在独立进程重载，比较固定真实样本的预测结果，并再次评估测试集。
5. 输出结果 JSON、两张图、中文学习说明和可再次运行的入口。

边界：MACs 比值不是实际速度倍数；本轮不测推理耗时，不做工业缺陷实验或 RK3568 部署。单种子、单 epoch 不能支持论文精度复现或显著性结论。数据下载校验采用 torchvision 内置 MD5；权重 SHA256 是下载后记录值，不是作者独立发布的签名。
